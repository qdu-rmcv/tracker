# 目标跟踪算法

## 输入与输出

输入：

- `/detector/armors` 中每块装甲板的相机系位姿
- TF 中相机到 `target_frame` 的变换

输出：

- `/tracker/target` 中目标中心、速度、yaw、角速度、半径和状态

## 多模型 EKF

### 整车模型

状态：

```text
[xc, v_xc, yc, v_yc, za, yaw, v_yaw, r]
```

用于估计整车中心和旋转半径。装甲板位置由中心、yaw 和半径推导。

### 装甲板模型

状态：

```text
[xa, v_xa, ya, v_ya, za]
```

用于目标角速度较低时直接跟踪当前装甲板位置。

### 前哨站模型

状态：

```text
[xc, yc, zc, yaw, v_yaw]
```

用于前哨站三块装甲板，包含索引学习、旋转/静止判定和高度修正。

## 状态机

| 状态 | 含义 |
| ---- | ---- |
| `LOST` | 无有效目标，需要重新初始化 |
| `DETECTING` | 短暂识别到目标，还未确认稳定 |
| `TRACKING` | 正常跟踪 |
| `TEMP_LOST` | 临时丢失，使用预测维持 |

## 目标匹配

每帧流程：

1. 根据上一帧状态预测当前装甲板位置
2. 过滤距离过远或高度异常的装甲板
3. 选择编号一致且位置/yaw 差最小的观测
4. 若匹配成功，用观测更新 EKF
5. 若匹配失败，进入临时丢失或重置

## 模型切换

普通目标在整车模型和装甲板模型之间切换：

- 当前是装甲板模型，`|v_yaw| > v_yaw_full_threshold` 时切到整车模型
- 当前是整车模型，`|v_yaw| < v_yaw_armor_threshold` 时切到装甲板模型

这种迟滞避免在临界角速度附近频繁抖动。
